## 3. 架构

```
iOSStudyApp/
  Common/
    MYTheme.{h,m}           # 颜色、卡片、按钮、阴影
    StudyDataStore.{h,m}    # 目录数据 + 进度/收藏/设置持久化
  Base/
    MYTabBarController
    MYNavigationController
  Modules/
    Home/                   # 首页、详情
    Learn/                  # 课程中心、分类列表
    Practice/               # 课时练习
    Resources/              # 资源列表、资源详情
    Settings/               # 设置与统计
```

**数据流：**

- 页面通过 `[StudyDataStore shared]` 读写  
- 变更后发送 `StudyDataDidChangeNotification`  
- 首页 / 学习 / 设置等监听通知并刷新  

**本轮不做：** 登录、系统推送、iCloud 同步、网络拉取课程、SwiftUI 重写。

## 4. 功能设计

### 4.1 首页

- 顶部进度卡：问候语、连续打卡、总进度、今日目标、**继续学习**  
- 筛选：全部 / 待学 / 已完成 / 收藏  
- 搜索：按标题或知识点过滤  
- 列表卡片展示标签、时长、完成与收藏状态  
- 点击进入课程详情；数据变更后自动刷新  

### 4.2 课程详情

- 主题色 banner + 正文卡片  
- 右上角收藏开关  
- **标记完成 / 取消完成**、**开始练习**  
- 进入详情时写入最近学习课时，供「继续学习」使用  
- 无测验数据时：隐藏练习入口或给出明确提示（实现时二选一，优先隐藏并文案说明）  

### 4.3 学习 Tab

- 分区一：分类网格 → `CourseListViewController`（分类下课时 + 完成状态）  
- 分区二：热门课程 → 直达详情  
- 数据来自 `StudyDataStore`，进度变化后刷新  

### 4.4 练习页

- 从详情进入；本地选择题  
- 展示进度、题目、选项；答题后高亮对错  
- 未答题不可进入下一题  
- 全部结束后展示得分，并累加学习时长  

### 4.5 资源

- 分组列表：精选资料 / 工具与源码 / 社区与面试  
- 点击进入资源详情（介绍 + 要点），不再仅弹 Alert  

### 4.6 设置

- 可编辑：昵称、每日目标（分钟）  
- 学习提醒开关（仅本地偏好，不做系统通知）  
- 真实统计：累计分钟、完成课数、收藏数  
- 重置进度（二次确认）  
- 关于页  

## 5. 视觉规范

通过 `MYTheme` 统一：

- 主色、浅主色、背景、卡片色、主/次/辅助文字色、成功色  
- 卡片圆角与软阴影  
- 主按钮样式  

各页面禁止继续散落硬编码主题色；沿用增强版浅蓝教育风，保持与现有品牌一致。

## 6. 数据与边界

**持久化（UserDefaults，经 StudyDataStore）：**

- 完成课时、学习时长、连续打卡相关、最近课时  
- 收藏、昵称、每日目标、提醒开关  

**目录数据：** 内存内置（课程、测验、资源）；本轮不强制外置 JSON。

**边界行为：**

| 场景 | 行为 |
|------|------|
| 无可继续课时 | 「继续学习」提示去挑选课程 |
| 某课无测验 | 隐藏练习入口或明确提示暂无题目 |
| 重置后 | 统计归零，列表与首页状态刷新 |
| 搜索无结果 | 空状态文案，不崩溃 |
